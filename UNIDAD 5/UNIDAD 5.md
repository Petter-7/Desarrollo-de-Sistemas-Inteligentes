## ACTIVIDAD 5.1

## **Investigación: Comunicación, planeación, modelado, construcción y despliegue en Ingeniería de Software**

### **1. Comunicación**

La comunicación es la primera etapa del proceso de desarrollo de software. Consiste en establecer un diálogo entre el cliente, los usuarios y el equipo de desarrollo para conocer las necesidades, expectativas y objetivos del proyecto.

Su propósito es comprender qué problema se desea resolver y qué características debe tener el sistema.

**Actividades principales:**

- Identificar las necesidades del cliente.
    
- Realizar entrevistas y reuniones.
    
- Recopilar los requisitos del sistema.
    
- Definir los objetivos del proyecto.
    
- Aclarar dudas y establecer acuerdos.
    

**Importancia:** Una buena comunicación permite evitar malentendidos, reducir errores y desarrollar un software que realmente cumpla con las necesidades del usuario.

### **2. Planeación**

La planeación consiste en organizar y establecer las actividades necesarias para desarrollar el software. En esta etapa se determinan los recursos, tiempos, costos y responsabilidades del equipo de trabajo.

Su objetivo es establecer una guía que permita desarrollar el proyecto de manera ordenada y eficiente.

**Actividades principales:**

- Definir el alcance del proyecto.
    
- Establecer fechas de entrega.
    
- Calcular costos y presupuesto.
    
- Asignar tareas y responsabilidades.
    
- Identificar posibles riesgos.
    
- Seleccionar herramientas y tecnologías.
    

**Importancia:** Permite controlar el desarrollo del proyecto, aprovechar mejor los recursos y evitar retrasos o gastos innecesarios.

### **3. Modelado**

El modelado consiste en representar visualmente cómo estará organizado y cómo funcionará el sistema antes de comenzar su construcción.

En esta etapa se utilizan diagramas y modelos que facilitan la comprensión de la estructura, los procesos y las funciones del software.

**Actividades principales:**

- Diseñar la arquitectura del sistema.
    
- Crear diagramas UML.
    
- Elaborar diagramas de casos de uso.
    
- Diseñar las bases de datos.
    
- Representar los procesos y flujos de información.
    
- Definir las interfaces del usuario.
    

**Herramientas utilizadas:**

- UML.
    
- Draw.io.
    
- Lucidchart.
    
- StarUML.
    

**Importancia:** Ayuda a detectar problemas de diseño antes de programar y facilita que todos los integrantes comprendan cómo debe funcionar el sistema.

### **4. Construcción**

La construcción es la etapa en la que se desarrolla el software mediante la programación. Se toman los diseños y modelos realizados anteriormente y se convierten en un sistema funcional.

En esta fase los programadores escriben código, integran componentes y realizan pruebas para comprobar que el sistema funcione correctamente.

**Actividades principales:**

- Escribir el código fuente.
    
- Crear interfaces y funcionalidades.
    
- Conectar y configurar bases de datos.
    
- Integrar los diferentes módulos.
    
- Realizar pruebas de funcionamiento.
    
- Corregir errores encontrados.
    

**Herramientas utilizadas:**

- Visual Studio Code.
    
- Android Studio.
    
- Git y GitHub.
    
- MySQL.
    
- Java, Python, JavaScript y PHP.
    

**Importancia:** Es la etapa donde las ideas y diseños se convierten en un producto de software que puede utilizarse para resolver un problema.

### **5. Despliegue**

El despliegue es la etapa en la que el software terminado se instala, configura y pone a disposición de los usuarios finales.

Su objetivo es entregar el sistema para que pueda utilizarse en un entorno real, ya sea mediante una página web, una aplicación móvil o un programa de escritorio.

**Actividades principales:**

- Instalar y configurar el software.
    
- Publicar aplicaciones en servidores.
    
- Configurar bases de datos en producción.
    
- Realizar pruebas finales.
    
- Capacitar a los usuarios.
    
- Supervisar el funcionamiento del sistema.
    
- Corregir problemas después de su publicación.
    

**Herramientas utilizadas:**

- Hosting y servidores.
    
- Docker.
    
- GitHub Actions.
    
- Servicios en la nube.
    
- Google Play Console.
    

**Importancia:** Permite que el producto desarrollado llegue a los usuarios y pueda utilizarse en condiciones reales.

### **Ejemplo práctico de las cinco etapas**

Imaginemos que una empresa necesita desarrollar un sistema para administrar sus ventas e inventarios.

|Etapa|Aplicación en el proyecto|
|---|---|
|Comunicación|Se habla con la empresa para conocer sus necesidades.|
|Planeación|Se establecen tiempos, costos y actividades.|
|Modelado|Se diseñan los diagramas, pantallas y base de datos.|
|Construcción|Se programa el sistema de ventas e inventarios.|
|Despliegue|Se instala el sistema y se entrega a la empresa.|

### **Conclusión**

Las etapas de comunicación, planeación, modelado, construcción y despliegue son fundamentales en la Ingeniería de Software, ya que permiten desarrollar sistemas de manera organizada y eficiente. Cada una cumple una función específica y contribuye a que el producto final tenga calidad y satisfaga las necesidades del usuario. Seguir estas etapas ayuda a reducir errores, aprovechar los recursos y facilitar el desarrollo de proyectos de software exitosos.
